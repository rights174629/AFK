# 🌿 세상에서 가장 느린 정원 (The Slowest Garden in the World) — v2.0 상세 제작 및 아키텍처 마스터 플랜

본 문서는 기존 `fire.html` (`Keep the Fire Alive`) 및 `server.js` 구조를 기반으로, **안티그래비티(Antigravity) IDE**에서 두 번째 협동형 멍때리기/잠수 웹 토이인 **"세상에서 가장 느린 정원 (`garden.html`)"**을 제작하기 위한 전면 개정판(v2.0) 기술 설계서입니다.

## 1. 프로젝트 개요 및 핵심 메커니즘 (v2.0 개정 사항 반영)

### 1.1 핵심 컨셉 및 성장 규칙 변경
- **슬로건**: "씨앗 하나를 심으면 현실 시간으로 한 달(30일) 동안 자라나는 단 하나의 거대한 도트 나무"
- **일일 성장 시스템 (Daily Time-Driven Growth)**:
  - 나무는 물을 줄 때마다 즉각 크는 것이 아니라, **토양에 수분이 유지된 상태에서 하루하루(실제 시간 경과)가 지날 때마다 점진적으로 성장**합니다.
  - **픽셀(px) 수치 완전 비공개**: UI 어디에도 "몇 픽셀 자랐는지", "현재 나무가 몇 픽셀인지"를 일절 표시하지 않습니다.
  - **나무 성장률(%) 배지**: 상단 좌측 `⏳ 머문 시간` 바로 옆에 `🌱 성장률: 0.0%` 배지를 배치하여, 30일(100%) 만개 목표 대비 현재 나무가 어느 정도 자랐는지 백분율(`0.0% ~ 100.0%`)로 직관적으로 보여줍니다.
- **물주기 및 수분 100% 무반응 규칙**:
  - 여러 사람이 함께 키우는 나무이므로 `fire.html`의 장작 넣기처럼 **3분(180초)에 한 번씩 물주기**가 가능합니다 (1회 물주기 시 토양 수분 `+10%` 회복).
  - **수분 100% 포화 시 무반응 (No-Op)**: 토양 수분이 이미 `100%`일 때는 물주기 버튼을 눌러도 **아무런 반응(수분 증가, 물방울 연출, 효과음, 쿨다운 소모 등)이 일어나지 않도록** 차단하여 불필요한 과습/액션 낭비를 방지합니다.
  - 반대로 오랫동안 아무도 물을 주지 않아 수분이 `0%`가 되면 성장이 즉시 멈추고 나무가 **시듦(WITHERED)** 상태에 빠집니다.

### 1.2 시각·청각 디테일 및 실시간 자연환경 동기화
1. **첨부 레퍼런스 기반의 입체적이고 풍성한 도트 거목 (Lush Pixel-Art Oak Tree)**:
   - 단순한 1px 선형 줄기가 아니라, 첨부해주신 도트 나무 아트워크처럼 **강인하게 뻗은 뿌리(Buttress Roots), 명암이 살아있는 굵은 목질 기둥과 갈라지는 주가지/부가지, 그리고 4단계 명암 팔레트(`#142e1f` 딥 섀도우 → `#1f572c` 미드 그린 → `#479c38` 브라이트 그린 → `#9be964` 햇빛 하이라이트)로 겹겹이 쌓인 풍성한 구름형 수관(Canopy Clusters)**을 절차적(Procedural) 도트 그래픽으로 렌더링합니다.
2. **토양 수분 상태에 따른 극적인 토양 변화**:
   - **수분 충분 (`70% ~ 100%`, LUSH)**: 흙이 깊고 윤기 나는 다크 초콜릿 빛(`#28180e`)을 띠며, 지면 위가 풍성한 밝은 연두색 잔디 도트, 작은 들꽃, 이슬 맺힌 이끼, 작은 물웅덩이 반사광으로 덮입니다.
   - **적정 수분 (`30% ~ 69%`, HEALTHY)**: 차분한 갈색 토양(`#3f2a18`)과 표준 초록 잔디가 유지됩니다.
   - **메마름 (`1% ~ 29%`, THIRSTY) 및 시듦 (`0%`, WITHERED)**: 토양이 밝은 황토/회갈색(`#7c5c3e` → `#574435`)으로 푸석하게 바래고, **지표면 곳곳에 지그재그 형태의 도트 가뭄 균열(Cracks)과 갈라진 틈**이 나타나며 잔디가 누렇게 마릅니다.
3. **실제 시간(Real-Time) 기반 밤낮 교차 및 태양/달 일주운동**:
   - 접속자의 실제 시간(또는 서버 KST 기준 `00:00 ~ 23:59`)에 맞춰 **[새벽 여명(05~07시) → 한낮(07~17시) → 노을/황혼(17~19시) → 한밤중(19~05시)]** 하늘 그라데이션이 실시간으로 변화합니다.
   - 낮 시간대(`06:00 ~ 18:00`)에는 **도트 태양(Sun)**이 동쪽(좌측)에서 떠서 포물선 궤적을 그리며 서쪽(우측)으로 저물고, 밤 시간대(`18:00 ~ 06:00`)에는 **도트 달(Moon)과 별빛, 반딧불이**가 떠오릅니다. 태양의 고도와 위치에 따라 도트 나무 수관과 기둥의 하이라이트 방향도 함께 반응합니다.
4. **계절(봄·여름·가을·겨울) 및 실시간 날씨(맑음·비·눈·안개)**:
   - 실제 월(Month)을 기준으로 **봄(3~5월, 연분홍 벚꽃잎 하이라이트)**, **여름(6~8월, 짙고 푸른 녹음과 반딧불이)**, **가을(9~11월, 황금빛/단풍빛 수관 포인트와 낙엽)**, **겨울(12~2월, 나뭇가지 위와 지면에 소복이 쌓이는 도트 눈송이)** 테마가 반영됩니다.
   - 날씨 상태에 따라 하늘에서 **도트 빗줄기(Rain, 자연 수분 미세 공급)** 또는 **도트 함박눈(Snow)**이 내립니다.
5. **반딧불이 사운드 & 자연 ASMR (Web Audio API 합성)**:
   - 기존의 바람·빗소리·물방울 소리에 더해, 반딧불이가 깜빡일 때마다 **영롱하고 몽환적인 고음역대 벨/차임 신스 사운드(Firefly Twinkle Chime, 1.8kHz~3.2kHz 펜타토닉 하모닉스 + 미세 피치 글리산도)**가 잔잔하게 울려 퍼지도록 Web Audio API로 실시간 합성합니다.

## 2. 아키텍처 및 세부 구현 방법 (How to Build)

### 2.1 백엔드 (`server.js`) 시간 기반 성장 & 환경 동기화 모델

#### (1) 정원 상태 스키마 (`data/garden_state.json`)
```javascript
let gardenState = {
  moisture: 75.0,           // 토양 수분 게이지 (0.0 ~ 100.0%)
  status: 'HEALTHY',        // 'LUSH'(70~100%), 'HEALTHY'(30~69%), 'THIRSTY'(1~29%), 'WITHERED'(0%)
  growthProgress: 0.0,      // 30일 목표 대비 누적 성장률 (0.00% ~ 100.00%)
  activeGrowthSec: 0,       // 나무가 시들지 않고 건강하게 자란 누적 시간(초)
  totalWaterings: 0,        // 누적 물주기 횟수
  plantedAt: Date.now(),    // 씨앗을 심은 최초 시각
  weather: 'CLEAR',         // 'CLEAR'(맑음), 'RAIN'(비), 'SNOW'(눈), 'BREEZE'(산들바람)
  treeSeed: 20261015,       // 모든 접속자에게 동일한 거목 형태를 보장하는 시드
  lastSavedAt: Date.now()
};
```

#### (2) 하루 단위 성장률 계산 공식 (Time-Driven Growth Formula)
- 한 달(30일)은 총 `30 * 86,400초 = 2,592,000초`입니다.
- 서버의 1초 주기 타이머(`setInterval`)에서 `gardenState.moisture > 0` (`status !== 'WITHERED'`)일 때만 `activeGrowthSec`가 `1초`씩 증가합니다.
  - 토양 수분이 충분할 때(`LUSH`, `>= 70%`)는 광합성 보너스로 성장 속도가 `1.15배`, 메마를 때(`THIRSTY`, `< 30%`)는 `0.6배`, 시들었을 때(`0%`)는 `0배(정지)`가 됩니다.
- **성장률(%) 산출**:
  $$\text{growthProgress (\%)} = \min\left(100, \frac{\text{activeGrowthSec}}{2,592,000} \times 100\right)$$
- **생존 일차(Day 1 ~ 30) 산출**:
  $$\text{currentDay} = \min\left(30, \lfloor \frac{\text{activeGrowthSec}}{86,400} \rfloor + 1\right)$$

#### (3) 수분 100% 무반응(No-Op) 서버/클라이언트 가드
```javascript
// 클라이언트 & 서버 공통 가드 로직
if (gardenState.moisture >= 100.0) {
  // 수분이 100%일 때는 쿨다운을 소모하지 않고, 사운드/파티클/토스트 등 아무런 반응도 일으키지 않음
  return;
}
```

### 2.2 프론트엔드 풍성한 도트 거목 & 자연환경 렌더링 엔진 (`js/garden-canvas.js`)

첨부된 레퍼런스 나무 이미지의 조형미(뿌리에서 퍼져 올라가는 입체적 줄기, 어두운 잎 그림자 위에 밝은 연두색 잎 클러스터가 겹겹이 얹힌 형태)를 캔버스에서 재현하는 방법입니다.

1. **다층 볼륨 수관(Multi-Layer Volumetric Canopy) 렌더링**:
   - 성장률(`growthProgress: 0% ~ 100%`)에 비례하여 나무의 스케일因子(`scaleFactor = 0.08 + 0.92 * (growthProgress / 100)`)가 연속적으로 커집니다.
   - **기둥 & 뿌리(Trunk & Roots)**: 지면과 맞닿는 하단은 좌우로 넓게 퍼지는 뿌리(`Buttress Roots`)를 그리고, 기둥 내부는 세로 방향의 결(Bark Texture)을 따라 어두운 갈색(`#3b2114`), 중간 적갈색(`#6e3b1e`), 햇빛 받는 중앙부의 밝은 황토색(`#c27d44`) 도트를 배치합니다.
   - **수관 클러스터(Foliage Clusters)**: 중심 기둥에서 뻗어 나온 5~9개의 주가지 끝점을 중심으로 수십 개의 원형 도트 구름(Leaf Blobs)을 배치합니다.
     - **Layer 1 (심부 그림자)**: `#12201c` / `#1b3326` 도트로 수관 전체의 묵직한 실루엣과 가지 사이 음영을 먼저 채웁니다.
     - **Layer 2 (중간 잎사귀)**: `#245c2a` / `#337a32` 도트로 잎 덩어리의 볼륨을 형성합니다.
     - **Layer 3 (상단 하이라이트)**: 태양의 현재 각도(동쪽 일출 ~ 정오 ~ 서쪽 일몰)를 향해 있는 클러스터 상단 가장자리에 `#65b841` 및 `#a8eb67` 도트를 촘촘히 찍어 첨부 이미지와 동일한 픽셀아트 입체감을 완성합니다.
2. **토양 상태별 도트 텍스처 변환**:
   - `moisture < 30%`: 지면 잔디 너비가 줄어들고 흙 색상이 메마른 모래빛(`#6e5239`)으로 변하며, 사전 계산된 지그재그 픽셀 좌표 배열을 따라 검은 갈색 가뭄 균열(`#291c12`)이 선명하게 갈라집니다.
   - `moisture >= 70%`: 균열이 완전히 사라지고, 나무 밑동 주변으로 밝은 연두색 잔디(`#5ac54f`, `#8be065`)가 넓게 퍼지며, 작은 하늘색 물방울 반사 도트(`#38bdf8`)와 귀여운 새싹/들꽃 도트가 피어납니다.
3. **실시간 태양·달 궤도 및 계절/날씨 시스템**:
   - `new Date()`에서 현재 시각(`hours + minutes/60`)과 월(`month`)을 읽어옵니다.
   - **태양 궤도**: `06:00`(일출, 좌측 지평선) → `12:00`(남중, 화면 상단 중앙) → `18:00`(일몰, 우측 지평선)까지 삼각함수(`Math.sin`, `Math.cos`) 아크 궤적을 따라 도트 태양이 이동합니다.
   - **하늘 컬러 보간(Color Lerp)**: 새벽(보랏빛/분홍빛 여명) → 낮(청명한 하늘색) → 노을(주황/자주빛 황혼) → 밤(깊은 네이비/숲속 어둠)으로 RGB 값을 부드럽게 선형 보간합니다.

### 2.3 반딧불이 사운드 합성 (`js/garden-audio.js`)
- 외부 오디오 파일 없이 Web Audio API로 **반딧불이 반짝임 소리(Firefly Sound)**를 구현합니다.
- 밤 시간대이거나 반딧불이가 활성화될 때, `2.5초 ~ 5초`의 랜덤 간격으로 펜타토닉 음계(`C6, D6, E6, G6, A6, C7` — `1046Hz ~ 2093Hz`) 중 하나의 주파수를 선택해 `sine` + `triangle` 오실레이터를 짧게(`Attack 0.03s`, `Release 0.8s`) 울립니다.
- 반딧불이가 화면에서 밝게 점멸하는 순간과 사운드 트리거를 일치시켜 시청각적 힐링감을 극대화합니다.

## 3. 새 기능 구현 시 예상되는 오류 및 해결 계획 (Troubleshooting)

새로 추가된 **일일 성장, 수분 100% 무반응, 실시간 밤낮/계절/날씨, 풍성한 도트 나무, 반딧불이 오디오**를 구현할 때 발생할 수 있는 **8가지 핵심 오류와 대처 방안**입니다.

## 4. 크로스 디바이스 호환성 및 극한의 최적화 전략 (All-Device Optimization)

데스크톱, 태블릿, 저사양 스마트폰, 구형 노트북 등 **어떠한 기기에서든 수 시간 동안 켜두어도 발열 없이 부드럽게 돌아가도록** 다음 4단계 최적화를 적용합니다.

### 4.1 3-Layer 분리 렌더링 아키텍처 (CPU 점유율 90% 절감)
1. **Background Sky Layer (1분 주기 갱신)**: 하늘 그라데이션과 구름/원경 산맥은 매 프레임 계산하지 않고, 시간(분)이나 날씨가 바뀔 때만 갱신합니다.
2. **Static Tree & Soil Layer (`treeCacheCanvas`, 이벤트 기반 갱신)**: 가장 연산량이 많은 **풍성한 도트 거목(기둥 결 + 4단계 명암 수관 클러스터)과 토양(잔디/가뭄 균열)**은 오프스크린 캔버스에 딱 한 번 그려두고 재사용합니다.
3. **Dynamic Particle Layer (24~30fps 경량 루프)**: 매 프레임마다 움직여야 하는 **태양/달 위치, 비(Rain), 눈(Snow), 반딧불이(Fireflies), 물주기 물방울**만 고정 크기 오브젝트 풀(`TypedArray` 또는 사전 할당 배열)로 가볍게 그립니다.

### 4.2 기기 성능 및 배터리 절전 대응 (Adaptive Quality)
- **비가시성 완전 절전 (`Page Visibility API`)**: `document.hidden === true`일 때는 캔버스 렌더링과 반딧불이 사운드 생성을 즉시 일시 정지하여 백그라운드 CPU/GPU 사용량을 `0%`로 만듭니다.
- **모바일 터치 & Safe-Area 완벽 대응**:
  - `viewport-fit=cover` 및 `env(safe-area-inset-bottom)`을 적용하여 아이폰 노치/홈바 영역과 하단 물주기 버튼이 겹치지 않게 처리합니다.
  - 화면 폭 `640px` 이하 모바일에서는 상단 바 배지와 우측 컨트롤 패널이 자동으로 컴팩트하게 접히거나 정렬되어 나무 시야를 가리지 않도록 반응형 CSS를 구성합니다.
